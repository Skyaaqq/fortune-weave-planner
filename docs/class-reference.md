# 角色卡成长与兵种说明

2026-09-24 的本轮改动先补可查阅的事实资料，玩家培养方案继续沿用现版。角色卡九项个人成长率来自项目既有玩家热力图转录；职业成长修正另列在兵种说明，单位为百分点。两种数据不自动相加，也不把社区表的“兵种基础能力值”混入成长率。

兵种资料按已有职业 ID 对照[腾讯文档社区协作表](https://docs.qq.com/sheet/DV0N0VUZLSXRmUWFq?tab=lnafol)的职业名称逐行摘录。页面标明原表行号。考试字段包括社区作者给出的技能、票证与推荐等级；推荐等级不等于已证实的硬性门槛。具体委托、人物和章节解锁内容由剧透门动态加载，刷新后重锁。未对应或未核实的数值保持未知。

目前 Caladrius 与 Bardinger 的中文职业名对应尚未证实，Caladrius 暂用英文名；卫士幸运成长修正因腾讯表 +5、GameWith +15 冲突保持未知。穆在社区表的九项数值均比项目现值高 20，且表注称包含个人特技；角色卡保留既有数值并标注口径差异，避免重复叠加。其他成长差异只做提示，待实机或更可靠资料核对后再决定是否修正。
