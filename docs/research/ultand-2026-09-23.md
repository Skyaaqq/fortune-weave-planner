# 乌尔坦德培养目标核对

核对日期：2026-09-23。这是玩家策略修正，不修改角色成长、招募条件或路线可用性。职业中文沿用现有映射，未重新宣称官方译名已验证。

## 来源与分歧

- [GameWith 角色攻略](https://gamewith.jp/fefw/577319)（页面更新 2026-09-22）：推荐经 Diviner → Priest → Guardian，发挥枪术与白魔的前卫兼支援能力。本站本次更新到已有 Guardian 职业节点，不补造未收录职业的译名或机制。
- [近期玩家实际用法讨论](https://www.reddit.com/r/FE_Fortunes_Weave/comments/1wmx3c1/how_are_you_guys_using_ultand/)（核对当日）：有人采用 Guardian，有人更偏魔法输出或机动支援，也有天翼兵实验。这些是不同玩家的选择，未形成唯一最优方案。飞行报告提到额外训练成本，不能推广为所有路线的标准答案。
- [GameWith 驭龙兵资料](https://gamewith.jp/fefw/577441)：所列职业成长并不支持旧文案对 SPD / DEX 的笼统补强承诺。此次不据此填充整个职业成长数据库。

## 本站采用的分工

| 位置 | 培养目标 | 路径 | 可信度 |
| --- | --- | --- | --- |
| 凯伊线、单版本默认 | 枪术 / 白魔 / RES | 诅咒师 → 牧师 → 卫士 | medium |
| 迪托利希线第二版本 | 物理 / 飞行机动 | 飞鸵兵 → 天翼兵 → 驭龙兵 | experimental |

把主版本分配到凯伊线、飞行实验分配到迪托利希线，是本站为合流安排的分工推断，**不是资料证明的路线限制**。只练一份时，迪托利希线也可选枪＋白魔方向。社区飞行个案不等于整条飞行培养链已验证最优，因此保留实验标记并取消旧 S/A+ 排名。

旧数据把凯伊的目标写成物理 / 机动 / DEX，职业却走主教；迪托利希目标写成 MAG / RES，职业却走飞行。此次同步修正角色卡、固定成员说明、第二版本说明和合流卡，并把目标集中到 BuildGuide。已解决的乌尔坦德历史警告移除，其他角色未核对的差异提示保留。

原始迁移快照保持不变；乌尔坦德从旧指南逐字一致性检查中明确豁免，另有专项测试约束路径、目标、实验标记、来源和跨组件一致性。
