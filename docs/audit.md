# 原型审计与迁移验收

基线：`1e8425c`，原型可通过 Git 历史读取。用户计划实际路径为 `docs/refactor_plan.md`。

## 功能清单

- 暖白 / 深色主题、六个锚点导航、速览、来源说明。
- 四路线：固定人数 4 / 4 / 5 / 5，主归属各 8，合流分类人数 4 / 5 / 5 / 7。
- 统一角色卡：中英文名、等比例头像、招募条件、有效成长、定位、理由、标签、职业及条件分支。
- 当前路线跨分类搜索、只看合流、招募复选框与进度条。
- 8 个核心 + 3 个可选合流项目。
- 53 行成长数据、9 项基础属性、3 项派生值、四路线状态、CSV / TSV。
- 双确认防剧透、重新隐藏、刷新重锁、前置与特殊条件清单持久化。
- Wiki 请求失败及图片失败文字回退。

## 已发现的问题与处理依据

- 原型成长表显示 3 位后期角色姓名，即使路线列为锁定。新版保留 53 个行位，锁定行不含姓名、头像、数值；确认后才加载完整数据。导出遵守同一规则。
- 原型乌尔坦德、妮涅等合流摘要与职业指南不一致。`e25dc63` 到 `a956cf8` 的历史明确显示职业建议已更新，而旧摘要未更新。迁移保留摘要作为历史 Meta，并标记不一致，不静默改写玩家结论；当前职业路线仍沿用基线指南。
- 53 行 TOTAL 均与九项属性总和一致。迁移后 TOTAL、AVG、BEST OFF 由基础值计算。
- 主招卡的 S/R 门槛与成长表矩阵一致。原卡省略的物品条件由统一招募数据补全。
- 原型无构建、类型检查或测试；Pages 上传整个仓库。新工作流只在 main 验证通过后部署 dist。
- 已有 `fw-planner:*` / `fw-theme` 需无损读取迁移，保留旧键，读取或写入失败需明确反馈。

4. 单元 / 浏览器验收、移动端与异常路径。
5. CI、维护文档、分步提交与 PR。
