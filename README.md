# Fire Emblem Fortune's Weave / 万缕千丝 玩家规划器

单页静态攻略工具，包含：

- 四路线标签页与统一角色卡
- 中英文角色名
- 招募条件、成长率与培养建议
- 双版本 / 因果合流培养建议
- 双重防剧透锁
- Fire Emblem Wiki 在线角色头像（失败时自动文字回退）
- 简体中文实机职业名校正

## GitHub Pages

本仓库设计为直接发布 `main` 分支根目录的 `index.html`。

> 注意：若仓库保持 Private，GitHub Pages 需要支持私有仓库 Pages 的账户方案。
> Pages 站点本身通常仍是公开访问的。
